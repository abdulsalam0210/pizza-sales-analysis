# 🍕 Pizza Sales Report (2015)

## 📌 Project Overview
This project analyzes **pizza sales data (Jan 2015 – Dec 2015)** to gain insights into customer preferences, sales performance, and business trends.  
The analysis was conducted using **Power BI** with interactive dashboards showcasing sales by category, size, time, and product performance.

---

## 🛠 Tools & Technologies Used
- **Power BI Desktop** – Interactive dashboards and visualizations  
- **SQL** – Data extraction & preparation  
- **Excel** – Data preprocessing & exploration  
---

## 📊 Key Insights
- **Total Revenue**: **817.86K**  
- **Total Orders**: **21,350**  
- **Total Pizzas Sold**: **49,574**  
- **Average Order Value**: **38.31**  
- **Average Pizzas per Order**: **2.32**  

### Sales Trends
- 📅 **Busiest months**: **January & July**  
- 📆 **Busiest days**: **Weekends (Friday & Saturday evenings)**  
- 🍕 **Best-selling category**: **Classic pizzas (14,888 sold)**  
- 📏 **Most popular size**: **Large pizzas (45.89% of sales)**  

### Best & Worst Sellers
- 🔝 **Top 5 by Revenue**: Thai Chicken, Barbecue Chicken, California Chicken, Classic Deluxe, Spicy Italian  
- 🔝 **Top 5 by Quantity**: Classic Deluxe, Barbecue Chicken, Hawaiian, Pepperoni, Thai Chicken  
- 🔝 **Top 5 by Orders**: Classic Deluxe, Hawaiian, Pepperoni, Barbecue Chicken, Thai Chicken  
- 🔻 **Bottom Performers**: Spinach, Mediterranean, Calabrese, Green Garden, Brie Carre
